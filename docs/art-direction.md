# Collector's table redesign

Completed 10 October 2026, following the reference image supplied in the conversation.

The interactive scene uses genuine Three.js geometry for the walnut/leather table, brass edge, lamp, game box, paper layers, cards, chips, and miniature buildings. The illustrations sit inside live card faces; the scene is not a single flat reference image.

The existing game rules, card values, and property identifiers are preserved. City headings are a visual district theme; original property names remain printed below their illustrations. Rent amounts come directly from the shared game definitions.

## Generated asset

- Tool: built-in `image_gen` (not the CLI fallback).
- Committed asset: `public/assets/deal-illustrations.webp` (2048 × 2048, 842,416 bytes).
- Layout: 4 × 4 illustration atlas. It is loaded locally; no remote image API is used during play.
- UI borders, typography, currency values, rent tables, wild-card colour wheel, banknote ornament, and card backs are drawn by `public/card-art.mjs`. These remain crisp and match the live rules.
- Physical materials and procedural wood/leather are generated by `public/tabletop.mjs`.
